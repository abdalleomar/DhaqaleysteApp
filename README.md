Dhaqaleyste is a cross-platform marketplace mobile application built using .NET MAUI and ASP.NET Core Web API.

The application allows users to browse products, upload products, manage inventory, and communicate with sellers.
✨ Features
User Login
Product Listing
Product Details
Shopping Cart
Product Categories
Search Products
Image Upload
Video Upload
Admin Dashboard
REST API Integration
